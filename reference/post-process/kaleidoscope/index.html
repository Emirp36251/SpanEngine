Kaleidoscope

ポストプロセスのエフェクト

エディタでは、Assets → Create → Post-Process Profile で、プロファイルを作ります。使い方は、エフェクトの使い方を見てください。

パラメーター

Section titled “パラメーター”
表示名 変数名 型 範囲 説明
Intensity _Intensity 数値 0.0 〜 1.0 適用度 (0.0 ～ 1.0)
Segments _Segments 数値 2.0 〜 24.0 万華鏡の分割数。偶数にすると綺麗に鏡像が繋がります
Rotation Angle _RotationAngle 数値 0.0 〜 360.0 万華鏡の回転角度
Center Offset & Scale _CenterAndScale 色

数値の初期値は、範囲の最小値です。色の初期値は、白です。
