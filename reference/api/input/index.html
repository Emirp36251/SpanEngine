Input

入力を読むための、静的な関数です。システムの中から、Input::GetKeyDown(Key::Space) のように呼びます。

キーボード Polling

Section titled “キーボード Polling”

GetKey

Section titled “GetKey”

指定したキーが押されているか

GetKeyDown

Section titled “GetKeyDown”

指定したキーが「このフレームで」押されたか

GetKeyUp

Section titled “GetKeyUp”

指定したキーが「このフレームで」離されたか

GetKeyRepeat

Section titled “GetKeyRepeat”

指定したキーがリピート発火するタイミングかどうかを取得する。

引数 説明
key 判定するキー
interval リピート間隔(秒)
initialDelay リピート開始までの遅延(秒)

GetKeyHoldDuration

Section titled “GetKeyHoldDuration”

指定したキーが押され続けている時間。

GetAnyKeyDown

Section titled “GetAnyKeyDown”

何らかのキーが「このフレームで」押されたかどうかを取得する。

修飾キー便利関数

Section titled “修飾キー便利関数”

IsShiftHeld

Section titled “IsShiftHeld”

Shiftキーが押されているかどうか

IsCtrlHeld

Section titled “IsCtrlHeld”

Ctrlキーが押されているかどうか

IsAltHeld

Section titled “IsAltHeld”

Altキーが押されているかどうか

Mouse

Section titled “Mouse”

GetMousePosition

Section titled “GetMousePosition”

マウスカーソルの位置を取得する。ウィンドウ左上を原点としたピクセル座標。

GetMouseDelta

Section titled “GetMouseDelta”

マウスカーソルの移動量を取得する。ウィンドウ左上を原点としたピクセル座標。

GetMouseWheel

Section titled “GetMouseWheel”

マウスホイールの回転量を取得する。正の値は上方向、負の値は下方向。

SetCursorVisible

Section titled “SetCursorVisible”

マウスカーソルの表示/非表示を切り替える

SetLockCursor

Section titled “SetLockCursor”

マウスカーソルをウィンドウ中央に固定するかどうかを切り替える

IsCursorVisible

Section titled “IsCursorVisible”

マウスカーソルが表示されているかどうかを取得する

IsCursorLocked

Section titled “IsCursorLocked”

マウスカーソルがウィンドウ中央に固定されているかどうかを取得する

ゲームパッド Polling

Section titled “ゲームパッド Polling”

IsGamepadConnected

Section titled “IsGamepadConnected”

指定したスロットのゲームパッドが接続されているか

GetConnectedGamepadCount

Section titled “GetConnectedGamepadCount”

現在接続されているゲームパッドの台数

GetButton

Section titled “GetButton”

指定したゲームパッドのボタンが押されているか

GetButtonDown

Section titled “GetButtonDown”

指定したゲームパッドのボタンが「このフレームで」押されたか

GetButtonUp

Section titled “GetButtonUp”

指定したゲームパッドのボタンが「このフレームで」離されたか

GetButtonRepeat

Section titled “GetButtonRepeat”

指定したゲームパッドのボタンがリピート発火するタイミングかどうかを取得する。

GetButtonHoldDuration

Section titled “GetButtonHoldDuration”

指定したゲームパッドのボタンが押され続けている時間。

GetAnyButtonDown

Section titled “GetAnyButtonDown”

何らかのゲームパッドボタンが「このフレームで」押されたかどうかを取得する。

GetAxis

Section titled “GetAxis”

指定したゲームパッドの軸の値を取得する。-1.0～1.0の範囲で返す。

IsTouchpadTouched

Section titled “IsTouchpadTouched”

タッチパッド上の指定タッチポイントが接触しているか。

GetTouchpadPosition

Section titled “GetTouchpadPosition”

タッチパッド上の指定タッチポイントの正規化座標を取得する。

GetTouchpadButton

Section titled “GetTouchpadButton”

タッチパッドのクリックボタンが押されているか。

SwapGamepadSlots

Section titled “SwapGamepadSlots”

指定した2つのゲームパッドスロットの割り当てを入れ替える。

GetGamepadVisualProfile

Section titled “GetGamepadVisualProfile”

指定したゲームパッドの見た目のプロファイルを取得する。

最終アクティブデバイス検出

Section titled “最終アクティブデバイス検出”

GetLastActiveDeviceType

Section titled “GetLastActiveDeviceType”

最後に明示的な操作があった入力デバイスの種別を取得する。

GetLastActiveGamepadIndex

Section titled “GetLastActiveGamepadIndex”

最後にアクティブだったゲームパッドのスロット番号。(未検出: -1)

WasLastInputFromGamepad

Section titled “WasLastInputFromGamepad”

最後の操作がゲームパッドからだったか。

WasLastInputFromKeyboardMouse

Section titled “WasLastInputFromKeyboardMouse”

最後の操作がキーボード/マウスからだったか。

GetKeyDisplayName

Section titled “GetKeyDisplayName”

キーのユーザー向け表示名を取得する。

GetAxisDisplayName

Section titled “GetAxisDisplayName”

軸のユーザー向け表示名を取得する。

WasGamepadConnectedThisFrame

Section titled “WasGamepadConnectedThisFrame”

指定したゲームパッドが「このフレームで」接続されたか。

WasGamepadDisconnectedThisFrame

Section titled “WasGamepadDisconnectedThisFrame”

指定したゲームパッドが「このフレームで」切断されたか。

Section titled “内部用”

GetDroppedFiles

Section titled “GetDroppedFiles”

ドラッグ&ドロップで落とされたファイルのパスを取得する。フルパス。

Game Input Routing

Section titled “Game Input Routing”

SetGameInputEnabled

Section titled “SetGameInputEnabled”

ゲームロジック側の入力を有効/無効にする。 無効にすると、ゲームロジック側の GetGameKey/GetGameButton/GetGameAxis が常に false/0 を返すようになる。

IsGameInputEnabled

Section titled “IsGameInputEnabled”

ゲームロジック側の入力が有効かどうかを取得する。

GetGameKey

Section titled “GetGameKey”

ゲーム用の GetKey です。ゲームの入力が無効なときは、常に false を返します。

GetGameKeyDown

Section titled “GetGameKeyDown”

ゲーム用の GetKeyDown です。ゲームの入力が無効なときは、常に false を返します。

GetGameKeyUp

Section titled “GetGameKeyUp”

ゲーム用の GetKeyUp です。ゲームの入力が無効なときは、常に false を返します。

GetGameKeyRepeat

Section titled “GetGameKeyRepeat”

ゲーム用の GetKeyRepeat です。ゲームの入力が無効なときは、常に false を返します。

GetGameButton

Section titled “GetGameButton”

ゲーム用の GetButton です。ゲームの入力が無効なときは、常に false を返します。

GetGameButtonDown

Section titled “GetGameButtonDown”

ゲーム用の GetButtonDown です。ゲームの入力が無効なときは、常に false を返します。

GetGameButtonRepeat

Section titled “GetGameButtonRepeat”

ゲーム用の GetButtonRepeat です。ゲームの入力が無効なときは、常に false を返します。

GetGameAxis

Section titled “GetGameAxis”

ゲーム用の GetAxis です。ゲームの入力が無効なときは、常に 0 を返します。
