System

システムの中から呼べる関数の一覧です。Span::System を継承したクラスの中で、そのまま呼べます。書き方は、システムを書くを見てください。

ライフサイクルと基本

Section titled “ライフサイクルと基本”

OnGameStart

Section titled “OnGameStart”

Playモード開始時に1回だけ呼ばれます。初期化やスポーン処理に使用します。

OnGameStop

Section titled “OnGameStop”

Playモード終了時に呼ばれます。リセット処理などに使用します。

OnCreate

Section titled “OnCreate”

初期化時に1回だけ呼び出されます。リソースのロードや事前計算に使用します。

OnUpdate

Section titled “OnUpdate”

毎フレーム呼び出されます。ここにゲームロジックを記述します。

OnFixedUpdate

Section titled “OnFixedUpdate”

固定フレームで呼び出される更新処理

OnDestroy

Section titled “OnDestroy”

終了時に呼び出されます。メモリ解放やクリーンアップに使用します。

IsEnabled

Section titled “IsEnabled”

システムが有効かどうか

GetName

Section titled “GetName”

システム名を取得します。

SetName

Section titled “SetName”

システム名を設定します。

GetRunMode

Section titled “GetRunMode”

システムの実行モードを取得します。

SetRunMode

Section titled “SetRunMode”

システムの実行モードを設定します。

GetExecutionGroup

Section titled “GetExecutionGroup”

システムの実行フェーズを取得します。

SetExecutionGroup

Section titled “SetExecutionGroup”

システムの実行フェーズを設定します。

Query

Section titled “Query”

指定したコンポーネントを持つエンティティのリストをクロージャで処理します。

例

ParallelQuery

Section titled “ParallelQuery”

並列処理でクエリを実行します。

GetWorld

Section titled “GetWorld”

所属しているワールドを取得します。

戻り値: ワールドへのポインタ

GetCommandBuffer

Section titled “GetCommandBuffer”

このシステム専用のコマンドバッファを取得します。

SetActiveHierarchy

Section titled “SetActiveHierarchy”

指定エンティティ以下の階層(自身+子孫)すべての Active を安全に一括設定します。

引数 説明
root 起点となるエンティティ
active 設定するアクティブ状態

HasComponent

Section titled “HasComponent”

指定したエンティティが指定したコンポーネントを持っているかどうかを確認します。

GetComponent

Section titled “GetComponent”

指定したエンティティの指定したコンポーネントを取得します。

時間とログ

Section titled “時間とログ”

GetDeltaTime

Section titled “GetDeltaTime”

現在のフレームのデルタタイムを取得します。

GetUnscaledDeltaTime

Section titled “GetUnscaledDeltaTime”

現在のフレームの現実時間デルタタイムを取得します。

GetFixedDeltaTime

Section titled “GetFixedDeltaTime”

現在のフレームの固定デルタタイムを取得します。

GetTotalTime

Section titled “GetTotalTime”

ゲーム開始からの経過時間(秒)を取得します。

GetTimeScale

Section titled “GetTimeScale”

現在の時間の進み具合を取得します。1.0 = 等倍、0.0 = 停止、0.5 = スロー

SetTimeScale

Section titled “SetTimeScale”

ゲーム内の時間の進み具合を設定します。1.0 = 等倍、0.0 = 停止、0.5 = スロー

LogInfo

Section titled “LogInfo”

ログ出力します。

LogWarning

Section titled “LogWarning”

警告ログ出力します。

LogError

Section titled “LogError”

エラーログ出力します。

エンティティの検索

Section titled “エンティティの検索”

FindEntityWithName

Section titled “FindEntityWithName”

指定した名前を持つ最初のエンティティを検索します。

引数 説明
name 検索する名前

戻り値: 見つかったエンティティ、存在しない場合はEntity::Null

FindEntitiesWithName

Section titled “FindEntitiesWithName”

指定した名前を持つ全てのエンティティを検索します。

FindChildWithName

Section titled “FindChildWithName”

指定した親の直下の子から、名前が一致するものを検索します。

Unityの transform.Find に相当します。

FindEntityWithTag

Section titled “FindEntityWithTag”

指定したタグを持つ最初のエンティティを検索します。

引数 説明
tag 検索するタグ文字列

戻り値: 見つかったエンティティ、存在しない場合はEntity::Null

FindEntitiesWithTag

Section titled “FindEntitiesWithTag”

指定したタグを持つ全てのエンティティを検索します。

引数 説明
tag 検索するタグ文字列

GetComponentInParent

Section titled “GetComponentInParent”

自分自身から祖先方向に辿り、最初に見つかった T コンポーネントを取得します。

戻り値: 見つかったコンポーネントのポインタ、存在しない場合はnullptr

GetComponentInChildren

Section titled “GetComponentInChildren”

自分自身から子孫方向へ深さ優先で辿り、最初に見つかった T コンポーネントを取得します。

戻り値: 見つかったコンポーネントのポインタ、存在しない場合はnullptr

IsAlive

Section titled “IsAlive”

エンティティが生存しているかどうかを確認します。

FindEntityByUUID

Section titled “FindEntityByUUID”

UUIDからエンティティを検索します。無効化されているエンティティも対象です。

引数 説明
uuid 検索するUUID

戻り値: 見つかったエンティティ、存在しない場合はEntity::Null

GetUUID

Section titled “GetUUID”

エンティティのUUIDを取得します。

戻り値: UUID。IDComponentを持たない場合は0

階層 (親子関係)

Section titled “階層 (親子関係)”

GetParent

Section titled “GetParent”

親エンティティを取得します。

戻り値: 親エンティティ、ルートの場合はEntity::Null

GetChildren

Section titled “GetChildren”

直下の子エンティティを全て取得します。孫以降は含みません。

GetChildCount

Section titled “GetChildCount”

直下の子エンティティの数を取得します。

GetRoot

Section titled “GetRoot”

階層の最上位(ルート)エンティティを取得します。親がいなければ自分自身を返します。

IsChildOf

Section titled “IsChildOf”

ancestor が entity の祖先(親、親の親…)であるかどうかを確認します。

自分自身は含みません。IsChildOf(A, A) は false です。

Transform の操作

Section titled “Transform の操作”

GetWorldMatrix

Section titled “GetWorldMatrix”

親子階層を考慮したワールド行列をその場で計算して返します。

LocalToWorldは1フレーム遅れるため、Logicフェーズで最新値が必要な場合はこちらを使います。

GetWorldPosition

Section titled “GetWorldPosition”

親子階層を考慮したワールド座標をその場で計算して返します。

GetWorldRotation

Section titled “GetWorldRotation”

親子階層を考慮したワールド回転をその場で計算して返します。

GetWorldScale

Section titled “GetWorldScale”

親子階層を考慮したワールドスケールをその場で計算して返します。

SetWorldPosition

Section titled “SetWorldPosition”

ワールド座標で位置を設定します。親がいる場合は親の逆行列でローカルへ変換します。

GetDistance

Section titled “GetDistance”

2つのエンティティのワールド座標間の距離を返します。

SetWorldRotation

Section titled “SetWorldRotation”

ワールド回転を設定します。親がいる場合は親の逆回転を掛けてローカルへ変換します。

Translate

Section titled “Translate”

移動させます。

引数 説明
entity 対象のエンティティ
delta 移動量
space Local: 自身の向きに沿って移動、World: ワールド軸に沿って移動

Rotate

Section titled “Rotate”

回転させます。

引数 説明
entity 対象のエンティティ
eulerDegrees 回転量 (X=Pitch, Y=Yaw, Z=Roll、単位は度)
space Local: 自身の軸で回転、World: ワールド軸で回転

GetEulerAngles

Section titled “GetEulerAngles”

ローカル回転をオイラー角(度)で取得します。

戻り値: X=Pitch, Y=Yaw, Z=Roll (単位は度)

SetEulerAngles

Section titled “SetEulerAngles”

ローカル回転をオイラー角(度)で設定します。

引数 説明
eulerDegrees X=Pitch, Y=Yaw, Z=Roll (単位は度)

GetForward

Section titled “GetForward”

ワールド空間での前方向(Z+)ベクトルを取得します。

GetRight

Section titled “GetRight”

ワールド空間での右方向(X+)ベクトルを取得します。

GetUp

Section titled “GetUp”

ワールド空間での上方向(Y+)ベクトルを取得します。

LookAt

Section titled “LookAt”

指定したワールド座標を向くように回転させます。

LookAt

Section titled “LookAt”

指定したエンティティの方を向くように回転させます。

シーンの切り替え

Section titled “シーンの切り替え”

LoadScene

Section titled “LoadScene”

現在のシーンを破棄し、指定したシーンを新しく同期ロードします。

引数 説明
sceneNameOrPath シーン名またはアセットの相対パス

戻り値: ロードの可否

LoadSceneAdditive

Section titled “LoadSceneAdditive”

現在のシーンを維持したまま、別のシーンのエンティティを同期的に加算ロードします。

引数 説明
sceneNameOrPath シーン名またはアセットの相対パス

戻り値: 加算ロードの可否

LoadSceneAsync

Section titled “LoadSceneAsync”

現在のシーンを破棄し、指定したシーンを新しく非同期ロードします。

引数 説明
sceneNameOrPath シーン名またはアセットの相対パス

戻り値: 進捗・完了状態を取得できるハンドル(失敗時はnullptr)

LoadSceneAdditiveAsync

Section titled “LoadSceneAdditiveAsync”

バックグラウンドのスレッドでシーンを非同期にロードし、完了後にメインシーンへ自動マージします。

引数 説明
sceneNameOrPath シーン名、またはアセットの相対パス

戻り値: 進捗・完了状態を取得できるハンドル(失敗時はnullptr)

MarkPersistentAcrossScenes

Section titled “MarkPersistentAcrossScenes”

指定したエンティティ階層を、シーン遷移を跨いで破棄されないようにします。

引数 説明
root 永続化するルートエンティティ

画面の遷移

Section titled “画面の遷移”
