設定とセーブ

遊ぶ人が残すデータは、2 種類に分かれます。

種類 何を残すか 例
設定 その パソコンの、遊びかたの好み 音量、全画面、言語、マウスの感度
セーブ その 遊びの進み具合 場所、持ち物、倒した敵

設定は、セーブを読み込んでも、変わりません。逆に、セーブは、設定とは関係なく、スロットごとに、分かれます。

設定

Section titled “設定”

読む、書く

Section titled “読む、書く”

システムの中から、GetSetting と SetSetting で、キーを指定して、扱います。

  • キーは、"Audio/MasterVolume" のように、/ で、グループを分けます。
  • 使える型は、bool、int、float、double、std::string と、それらの std::vector です。
  • 文字列は、GetSetting("Game/Language", "ja") のように、既定値に、文字列の定数を渡せます。
  • SaveSettings() を呼ばなくても、ゲームを終了するときに、書き込まれます。

読み出しの順番です。前の段で見つかれば、そこで決まります。

順 値の元
1 プレイヤーが変えた値 (ユーザー値)
2 プロジェクトの初期値 (Project Settings の Player Defaults)
3 設定を定義したときの、初期値
4 GetSetting に渡した、既定値

標準で用意されている設定

Section titled “標準で用意されている設定”

次のキーは、エンジンが、はじめから、用意しています。

キー 型 働き
Audio/MasterVolume、Audio/BGMVolume、Audio/SEVolume、Audio/VoiceVolume、Audio/AmbienceVolume float (0 から 1) 各バスの音量。変えると、音に反映される
Video/Fullscreen bool 全画面。書き出したゲームだけで、反映される
Video/VSync bool 垂直同期。書き出したゲームだけ
Video/TargetFPS int (0 から 1000) フレームレートの上限。0 は、制限なし
Video/Resolution 選択肢 窓の大きさ
Input/MouseSensitivity float (0.1 から 5) 視点の操作の倍率
Game/Language 選択肢 (ja、en) 言語。エンジンは、反映せず、ゲームが読んで文字を選ぶ

ノート

画面の設定には、専用の関数も用意されています。(SetFullscreen、SetVSync、SetResolution など) → 画面とシーン

自分の設定を作る

Section titled “自分の設定を作る”

ゲームだけの設定は、OnCreate で、定義します。

関数 型 引数
RegisterBoolSetting 真偽 キー、初期値
RegisterIntSetting 整数 キー、初期値、最小、最大
RegisterFloatSetting 小数 キー、初期値、最小、最大
RegisterStringSetting 文字列 キー、初期値
RegisterEnumSetting 選択肢 キー、選択肢の一覧、初期値
  • 最小と最大を決めると (最小 < 最大)、範囲の外の値は、範囲の中に、丸められます。
  • 最後の引数の SettingInfo に、表示名、分類、説明を入れられます。エディタの Save Data パネルの、Settings タブと、Project Settings の Player Defaults に出ます。
  • 定義した設定は、Project Settings の Player Defaults の Game (または Custom) のページに、並びます。そこで、プレイヤーの最初の値を決められます。(設定)

変わったことに気付く

Section titled “変わったことに気付く”

設定が変わるたびに、通し番号が増えます。GetSettingsRevision() で、取れます。前回と違うときだけ、設定を読み直す、という使いかたをします。

そのほかの関数

Section titled “そのほかの関数”
関数 働き
HasSetting(key) 設定が、存在するか
IsSettingModified(key) プレイヤーが、初期値から、変えているか
DeleteSetting(key) その設定を、初期値に戻す
ResetSettings() すべてを消して、保存する。「設定を初期化」のボタン用

保存される場所

Section titled “保存される場所”

設定は、%LocalAppData%\<Company Name>\<プロジェクト名>\settings.sav に、保存されます。Company Name は、Project Settings の Player で決めます。ファイルは、暗号化されています。

セーブ

Section titled “セーブ”

何が保存されるか

Section titled “何が保存されるか”

セーブは、スロットという名前で、複数残せます。1 つのスロットには、次のものが入ります。

中身 内容
エンティティの状態 Saveable コンポーネントを持つエンティティの、コンポーネントの値
作られたエンティティ 遊んでいる最中に作られた、Saveable のエンティティ (Prefab と、RuntimeSaveId)
消されたエンティティ シーンにあったのに、消えたものの一覧
ゲーム固有のデータ 自分で渡す、任意のデータ (下で説明)
付属の情報 スロットの名前、シーンの名前、遊んだ時間、日時

セーブしたい物に、Saveable コンポーネントを付けます。 付けていないエンティティは、保存されません。(プレイヤー、扉、拾えるアイテムなどに付けます。)

遊んでいる最中に 作った エンティティを、読み込みのときに、同じものとして見つけるには、Saveable の RuntimeSaveId に、重ならない名前を入れます。シーンに最初からあるエンティティは、空で構いません。

セーブと、ロード

Section titled “セーブと、ロード”

SaveToSlot、LoadFromSlot、DeleteSaveSlot は、成功したかを、bool で返します。EnumerateSaveSlots() は、スロットの一覧を返します。IsCorrupted が true のスロットは、壊れている (または、書き換えられた) ので、読み込めません。

ゲーム固有のデータを、セーブに入れる

Section titled “ゲーム固有のデータを、セーブに入れる”

「所持金」「クリアした面」のように、エンティティに結びつかないデータは、データの提供者を登録して、渡します。

  • 登録するのは、関数です。引数の型は、void(*)(nlohmann::ordered_json&) (集める) と、void(*)(const nlohmann::ordered_json&) (戻す) です。
  • static の関数にするので、状態を、static の変数や、グローバルの状態に置きます。
  • ここで書いた内容は、スロットの GlobalState に入ります。

保存される場所と、確かめかた

Section titled “保存される場所と、確かめかた”

セーブは、%LocalAppData%\<Company Name>\<プロジェクト名>\SaveGames\スロット名.sav に、保存されます。暗号化されていて、書き換えられると、壊れた扱いになります。

エディタでは、Save Data パネルで、スロットの中身を、見たり、書き換えたりできます。(アセットとデータのツール)

プロジェクト名を変えると

保存先の、フォルダの名前は、Company Name と プロジェクト名から、決まります。製品を出したあとに、どちらかを変えると、プレイヤーの、設定とセーブが、見つからなくなります。出す前に、決めておいてください。
