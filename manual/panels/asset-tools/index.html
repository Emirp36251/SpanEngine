アセットとデータのツール

素材とデータを、専用の画面で整えるパネルです。Window → Panels から開けます。

パネル 開く場所 (Window → Panels) 使いどころ
Model Viewer Asset モデルを見る。取り込みの設定を変える
Sprite Editor 2D 画像を、スプライトに分ける。9-Slice を決める
Terrain Tool Terrain 地形を、彫る、平らにする、塗る
Input Actions Input 入力のアクション (「ジャンプ」など) と、キーを結ぶ
Save Data General セーブデータと、プレイヤーの設定を、見て、直す

Model Viewer

Section titled “Model Viewer”

モデルを、ゲームに置く前に、見て、確かめるパネルです。

開き方は、Project パネルで、モデル (.fbx、.obj、.gltf) を ダブルクリックします。

見る

Section titled “見る”
操作 働き
Alt + 左ボタンのドラッグ モデルのまわりを回る
Alt + 中ボタンのドラッグ 平行に動かす
ホイール 近づく、離れる
F (または Frame (F)) モデルが収まる位置に、カメラを寄せる

上のバーです。

項目 働き
Grid 床のグリッド
Skybox 背景の空
Wireframe 面の線だけ
Mode Final Color、Albedo、Normal、Depth、Roughness、Metallic、Wireframe
Bounds Total Bounds (全体の箱)、Mesh Bounds (メッシュごとの箱)
Turntable モデルを、ゆっくり回して、光の当たりかたを見る

右の欄

Section titled “右の欄”
見出し 中身
(上) Combined Mode か Split Mode (Hierarchy) の表示。Meshes、Vertices、Indices、Triangles の数。三角形が 60000 を超えると、High Polygon Count の警告
Model Hierarchy モデルの中の、部品の木。Combine Meshes で取り込んだときは、使えない
Display Options Background Color、Skybox Rotation、Exposure、Camera Distance
Transform / Mesh / Material / Animation 取り込みの設定。Project パネルの、取り込みの画面と同じもの
Material Slots メッシュごとの、初期のマテリアル

取り込みの設定を変えたら、Apply & Reimport を押します。

Material Slots には、.mat を ドラッグして割り当てられます。このモデルを、Scene ビューへ置くと、割り当てたマテリアルが付きます。割り当てがない所は、赤い Unassigned (Fallback) と出ます。

Sprite Editor

Section titled “Sprite Editor”

画像を、いくつかの スプライト に分けるパネルです。2D のゲームや、UI で、1 枚の画像に、たくさんの絵を詰めたときに使います。

開き方は、Project パネルで、画像を ダブルクリックします。

操作

Section titled “操作”
操作 働き
右または中ボタンのドラッグ 画像を、平行に動かす
ホイール 拡大、縮小 (10% から 3200%)
左クリック スプライトを選ぶ (Multiple のとき)
Reset View 表示を初めに戻す

2 つのモード

Section titled “2 つのモード”

上の欄で、Single か Multiple を選びます。

モード 意味 右の欄
Single 画像 1 枚が、1 つのスプライト Border (L,B,R,T) (9-Slice の線)、Pivot (X,Y) (基準の点)
Multiple 画像を、複数のスプライトに分ける 選んだスプライトの Name、Rect (X,Y,W,H)、Border、Pivot。Delete Sprite

画像を分ける (Slice)

Section titled “画像を分ける (Slice)”

  1. 上の Slice を押します。

  2. Type を選びます。

    Type 働き
    Automatic 透明な所を境にして、絵ごとに、自動で分ける
    Grid By Cell Size 1 つのセルの大きさ (Pixel Size (W, H)) で、分ける
    Grid By Cell Count 列と行の数 (Columns (X)、Rows (Y)) で、分ける

  3. Execute Slice を押します。

9-Slice

Section titled “9-Slice”

ボタンの枠のように、角は変えずに、真ん中だけ伸ばしたい画像に使います。Border (L,B,R,T) に、左、下、右、上から何ピクセルを、角とするかを入れます。緑の線で、見えます。UI の Image コンポーネントの Type を Sliced にすると、伸ばしても、角が崩れません。

保存する

Section titled “保存する”

変えた内容は、Apply を押すまで、保存されません。やめるときは、Revert を押します。

Project パネルでは、スプライトに分けた画像の左に、矢印が出ます。開くと、分けたスプライトが並び、1 つずつ、使えます。

Terrain Tool

Section titled “Terrain Tool”

地形 (MeshField) を、彫ったり、塗ったりするパネルです。

はじめは、閉じています。使うには、次のようにします。

  1. Project パネルで、Create → Terrain → MeshField を選びます。.meshfield のファイルができます。

  2. Hierarchy で、空のエンティティを作って、MeshField コンポーネントを付けます。Asset の欄に、作った .meshfield を入れます。

  3. そのエンティティを選んで、Window → Panels → Terrain → Terrain Tool を開きます。

エンティティに MeshField が無いと、パネルには、Select a MeshField entity to use terrain tools. と出ます。

ツール

Section titled “ツール”

ボタンを押すか、数字のキーで、選びます。もう一度押すと、ツールが外れます。キーは、Scene ビューが選ばれているときに、効きます。

ツール キー 働き
Sculpt 1 地面を、盛り上げる。Ctrl を押しながらで、掘る
Flatten 2 クリックした場所の高さに、平らにそろえる
Smooth 3 凸凹を、なめらかにする
Paint 4 地面に、模様 (レイヤー) を塗る

使いかた

Section titled “使いかた”

Scene ビューで、地形の上に、マウスを動かすと、緑の輪 (ブラシ) が出ます。左ボタンを押したまま動かすと、塗れます。

操作 働き
Ctrl + ホイール ブラシの大きさを変える
Shift + ホイール ブラシの強さを変える

パネルの項目です。

項目 働き
Brush Size ブラシの大きさ (0.5 から 50 メートル)
Brush Strength ブラシの強さ (0 から 1)
Falloff ブラシの縁に向かって、どう弱くなるかの、カーブ
Paint Layer Paint のとき、塗るレイヤー (0 から 3)。模様の画像が、並ぶ
Save Terrain 変えた地形を、ファイルに保存する

保存を忘れずに

彫った地形は、Save Terrain を押すまで、ファイルに書き込まれません。押すと、Saved N chunk(s). と出ます。

Input Actions

Section titled “Input Actions”

「ジャンプ」「移動」のような アクションと、キーやボタンを、結ぶパネルです。ゲームのコードは、キーの名前ではなく、アクションの名前で、入力を読みます。そうすると、キーの割り当てを、あとから自由に変えられます。

入力の設定は、.inputmap のファイルに、保存されます。

ファイルを作って開く

Section titled “ファイルを作って開く”

  1. Project パネルで、Create → Input Map を選びます。.inputmap のファイルができます。

  2. ファイルを選びます。Inspector に、編集の画面が出ます。Open in Input Map Editor を押すと、大きな画面 (Input Actions パネル) で開きます。

画面の構成

Section titled “画面の構成”
場所 中身
左 コンテキストの一覧。Add Context で足す。右クリックで Duplicate、Delete
右の上 Context Name、Global
右 アクションの一覧。Add Action で足す。ごみ箱で消す

コンテキストは、アクションの集まりです。たとえば、Gameplay (遊んでいるとき) と、Menu (メニューを開いているとき) を、分けます。Global を入れたコンテキストは、いつでも効きます。

アクションに、キーを結ぶ

Section titled “アクションに、キーを結ぶ”

アクションの中に、バインディングを足します。1 つのアクションに、複数のバインディングを置けます。キーボードと、ゲームパッドを、両方結ぶ、などです。

  1. アクションの中の Add Binding を押します。

  2. Type を選びます。

    Type 使いどころ
    Key/Button キーや、ボタン
    Axis スティックなどの、連続した値

  3. 真ん中の欄のボタンを押して、キーを押します。Press a key... と出ます。割り当てられます。(Esc で、やめられます。) 右の矢印から、一覧で選ぶこともできます。

項目 意味
Scale 値の倍率。Axis のとき、数字を入れる。Key/Button のとき、+ か − のボタンで、符号を反転する (たとえば、「後ろへ進む」キーを、− にする)
Modifier 組み合わせのキー。たとえば、Ctrl を足すと、Ctrl を押しているときだけ効く。+ で足す。名前を押すと、消える
黄色い三角 同じコンテキストの中で、同じキーが、別のアクションにも使われている、という警告

Input Actions パネルで変えた内容は、自動でファイルに保存されます。

アクションを、ゲームのコードから読む方法は、システムを書くの API や、Input のリファレンスを見てください。

Save Data

Section titled “Save Data”

セーブデータと、プレイヤーの設定を、エディタの中で、見て、直すパネルです。2 つのタブがあります。

Save Slots タブ

Section titled “Save Slots タブ”

ゲームが保存した、セーブデータの一覧です。

項目 働き
Refresh 一覧を読み込み直す
Open in Explorer セーブの保存先のフォルダを開く
名前の欄と Save Play Session Play 中に、いまの状態を、その名前で保存する (Play 中だけ)
Record Snapshot いまの状態を、記録する (Play 中だけ)

左の一覧です。

  • 名前をクリックすると、右に、中身が出ます。
  • マウスを載せると、Scene、PlayTime、Updated が出ます。
  • 右クリックで、Delete です。
  • 赤い三角の行は、壊れている (または、書き換えられている) スロットです。

右の欄です。

項目 働き
中身の木 GlobalState (ゲーム全体の状態)、EntityStates (エンティティごと)、SpawnedEntities (作られたもの)、DestroyedEntityUUIDs (消えたもの)。値を、直接、書き換えられる
Save & Re-encrypt 書き換えた内容を、暗号化して、保存する
Discard 書き換えを、捨てる
Load This Slot このセーブを、いまのゲームに読み込む (Play 中だけ)

セーブデータは、暗号化されています。エディタは、読んで、書き換えて、もう一度暗号化します。

Settings タブ

Section titled “Settings タブ”

プレイヤーが、ゲームの中で変えた 設定 (音量、画面など) の、一覧です。

項目 働き
検索欄 設定を探す
Modified only 変えたものだけを出す
Save Now 保存する。未保存のときは、unsaved と出る
Reset All すべて初期に戻す (確認が出る。元に戻せません)
Open in Explorer 設定のファイルの場所を開く

行ごとに、設定の名前、値、エンジンの 初期値、初期に戻す矢印があります。名前に、マウスを載せると、説明が出ます。

下の Unregistered には、いまのゲームに定義がない、古い設定が並びます。ごみ箱で、消せます。

プレイヤーが最初に使う値は、ここではなく、Project Settings の Player Defaults で決めます。(設定)
