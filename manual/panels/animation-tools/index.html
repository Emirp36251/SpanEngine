アニメーションのツール

アニメーションは、2 つのファイルで作ります。

ファイル 役割 編集するパネル
Animation Clip (.anim) 1 つの動き (「歩く」「ジャンプ」など)。時間と値の、並び Animation Timeline
Animator Controller (.controller) 動きを、いつ、どう切り替えるか。ステートマシン Animator

物に付ける Animator コンポーネントに、Controller を入れると、動き出します。

全体の流れ

Section titled “全体の流れ”

  1. Project パネルで、Create → Animation Clip を選びます。.anim のファイルができます。ダブルクリックすると、Animation Timeline で開きます。

  2. Timeline で、動きを作って、Save を押します。

  3. Create → Animator Controller で、.controller を作って、ダブルクリックします。Animator パネルで開きます。

  4. Animator で、ステートを作り、Motion に、さっきのクリップを入れます。ステート同士を、トランジションで結びます。

  5. 動かしたいエンティティに、Animator コンポーネントを付けて、Controller の欄に、.controller を入れます。

  6. Play します。

Animation Timeline

Section titled “Animation Timeline”

クリップの中身を、時間の上に並べて、作るパネルです。

上のバー

Section titled “上のバー”
項目 働き
再生 / 一時停止、戻る、進む プレビューを再生する。1 フレームずつ戻る、進む
Loop クリップを、繰り返す
目のボタン プレビューの画面を、出す、隠す
Duration (秒) クリップの長さ
FPS 1 秒あたりのフレームの数 (1 から 240)
DopeSheet / Curves 表示の切り替え (下で説明)
Key Value 選んだキーの値
Save クリップを保存する

トラックを足す

Section titled “トラックを足す”

左の Tracks の + を押すと、足せるものが出ます。

メニュー トラック 使いどころ
Transform Transform Track (Position, Rotation, Scale) 物を、動かす、回す、拡大する
2D Sprite Sprite Track (Image.Sprite) 絵を、パラパラ漫画のように、切り替える
Image / UI Color.Alpha、Color.RGB 透明度や色を変える
RectTransform SizeDelta (Width / Height) UI の大きさを変える

トラックは、右クリックで、名前の変更 (Rename) と削除 (Delete Track) ができます。

キーを置く

Section titled “キーを置く”

キーは、「この時間に、この値」という点です。キーとキーの間の値は、自動で補われます。

操作 働き
トラックの行を ダブルクリック その時間に、キーを足す (値は、その時間の、いまの値)
キーをドラッグ 時間をずらす。複数のキーを選んで、まとめて動かせる
キーを選んで Delete キーを消す
キーを右クリック 値の編集、Delete Key(s)
上の目盛りをクリック 再生の位置 (いまの時間) を動かす
ホイール 時間の方向に、拡大、縮小
中ボタンのドラッグ (または Alt + 左ボタンのドラッグ) 横に動かす

Sprite Track には、Project パネルの、分けたスプライトを、行へドラッグして、置けます。

Curves で、動きの流れを整える

Section titled “Curves で、動きの流れを整える”

上の欄で Curves を選ぶと、値の変化が、曲線で見えます。キーを右クリックして、キーとキーの間の、つなぎかたを選べます。

種類 動き
Smooth なめらかな曲線
Linear まっすぐな線。折れ曲がる
Constant 次のキーまで、値を変えない。一瞬で切り替わる

Event (関数を呼ぶ)

Section titled “Event (関数を呼ぶ)”

クリップの下の、イベント専用の行に、イベントを置けます。再生が、その時間に来ると、エンティティの関数が、呼ばれます。足音を鳴らす、攻撃の当たりを出す、などに使います。

操作 働き
行を ダブルクリック イベントを足す
イベントを右クリック 編集の画面を開く
イベントをドラッグ 時間をずらす

編集の画面です。

項目 働き
Function Name 呼ぶ関数やメッセージの名前 (例: PlaySound)
Time (s) 呼ぶ時間
String Param / Float Param / Int Param 関数に渡す値

Animator

Section titled “Animator”

動きの、切り替えかたを決めるパネルです。丸いノード (ステート) と、矢印 (トランジション) で、組みます。

画面の構成

Section titled “画面の構成”
場所 中身
左 Parameters (切り替えの条件に使う値)
中央 ステートのキャンバス
右 State Inspector (選んだステート)。矢印を選ぶと、Transition Inspector

上のバーです。

項目 働き
Base Layer 一番上の階層に戻る (サブステートマシンの中にいるとき)
Auto Layout ノードを、きれいに並べ直す
Save 保存する

ステートを作る

Section titled “ステートを作る”

キャンバスの 何もない所を右クリックします。

メニュー 働き
Create State → Empty 新しいステートを作る
Create Sub-State Machine 小さなステートマシンを、1 つのノードにまとめる
Auto-Layout All Nodes ノードを並べ直す
Reset View / Origin 表示を初めに戻す

作ったステートを選ぶと、右の State Inspector で、設定します。

項目 働き
State Name ステートの名前
Tag 目印 (Attack など)
Motion 再生する Animation Clip。Project パネルから、ドラッグできる
Speed 再生の速さ (-10 から 10)
Loop Override / Looping クリップの設定を、上書きして、繰り返すかを決める
Mirror (Flip X) 左右を反転する
Make Transition 別のステートへの、矢印を作る
Set as Default State ゲームを始めたとき、最初に入るステートにする (星のしるし)
Delete State ステートを消す。そのステートへの矢印も、消える

ステートをつなぐ

Section titled “ステートをつなぐ”

  1. ステートを ダブルクリックするか、右クリックの Make Transition を選びます。

  2. つなぎたい 相手のステートを、クリックします。矢印ができます。(Esc か右クリックで、やめられます。)

特別なノード 意味
Entry 入口。Default State につながる
Any State どのステートからでも。ここから出る矢印は、いまのステートに関係なく、条件が合えば動く (「やられた」の切り替えなど)

矢印を選ぶと、Transition Inspector で、切り替えかたを決められます。

項目 働き
Has Exit Time 入れると、再生が Exit Time (0 から 1 の割合) に来てから、切り替える
Duration (s) 2 つの動きを混ぜながら、切り替える時間 (秒)
Conditions 切り替わる条件 (下で説明)。Add Condition で足す。条件がないときは、Unconditional で、すぐ切り替わる
Transition Blend Preview 混ぜ具合の図。青いピンが Exit Time、橙のピンが Duration。ドラッグして動かせる

矢印は、選んで Delete で消せます。

Parameters (条件に使う値)

Section titled “Parameters (条件に使う値)”

左の + から、パラメーターを足します。コードから値を入れて、切り替えの条件にします。

種類 値 条件の選択肢
Float 小数 Greater (>)、Less (<)
Int 整数 Greater (>)、Less (<)、Equals (==)、NotEqual (!=)
Bool 真偽 True、False
Trigger 一度だけの合図 Triggered

名前は、右クリックの Rename (F2) で変えられます。Duplicate (Ctrl + D)、Delete Parameter (Delete) も使えます。

コードから動かす

Section titled “コードから動かす”

Animator コンポーネントの関数で、パラメーターに、値を入れます。

システムの Process で、Animator を受け取って、値を入れます。(MoveState は、自分で作ったコンポーネントの例です。)

トリガーは、animator.SetTrigger("Jump"); で立てます。名前は、Animator のパラメーターの名前と、同じにします。詳しくは、Animator のリファレンスを見てください。

保存を忘れずに

Animation Timeline と Animator は、どちらも、Save を押すまで、ファイルに書き込まれません。
