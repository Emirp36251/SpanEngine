Span Engine

C++ と DirectX 12 のための、データ指向のゲームエンジン。エディタで組み立てて、C++ で書いて、そのまま製品にします。
ダウンロード最初の一歩
  1. 01

    Editor First

    すべての機能を、エディタの画面から操作できます。Hierarchy、Inspector、Scene、Game、Project、Console に加えて、プロファイラーと ECS デバッガーも標準です。

  2. 02

    Data Oriented

    データは、アーキタイプごとのチャンクに、SoA で並びます。コンポーネントは単純な構造体で、システムは Process 関数を 1 つ書くだけです。

  3. 03

    Native Performance

    C++20 と DirectX 12 で、ガベージコレクションはありません。スクリプトも C++ で、エディタを閉じずに、ビルドして読み込み直せます。
