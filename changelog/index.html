[0.5.0] - 2026-11-14

Section titled “[0.5.0] - 2026-11-14”

追加

Section titled “追加”
  • SPAN_COMPONENT() と SPAN_PROPERTY(...) の末尾に、; を付けても、読めるようになった。 IDE で、マクロの行のあとに Enter を押すと、次の行が 1 段下がることがある。同じ行に書く形 (SPAN_PROPERTY(Range(0, 100)) float X;) は、これまでも読めて、IDE の警告も出ない。末尾に ; を付けた形は、ビルドは通るが、Rider などでは、「関数定義が見つかりません」と警告が出ることがある。エディタの、コンポーネントを作る画面 (Apply to C++) も、同じに読む。
  • Project の Create メニューに、“C++ Data (ScriptableObject)” を足した。 データの型 (SPAN_DATA) のひな形を作る。ファイルの名前を、重複を避けて付けたときは、中の型の名前も、同じに変わる (C++ Component のひな形も同じ)。
  • 新しいプロジェクトの、フォルダのひな形を増やした。 Scripts/Data、Assets/Effects、Assets/Timelines、Assets/Physics (既定でオン)、Assets/Videos、Assets/Transitions、Assets/Terrain (既定でオフ)。Assets/Data の説明は、新しい .data に合わせた。
  • データアセット (SPAN_DATA) を追加した。 Unity の ScriptableObject に当たる。C++ の構造体に SPAN_DATA(Menu("Game/Player Stats"), FileName("NewPlayerStats")) を付けると、Assets > Create > Game > Player Stats から、.data のアセットを作れる。項目の書き方は、コンポーネントと同じ (SPAN_PROPERTY、Range などの属性、アセットの参照)。Inspector に、項目が出て、変えると、すぐ保存される (Undo と Redo も使える)。コードからは、コンポーネントの欄に DataRef<型> を置いて Get() で読むか、GetData<型>("Assets/Data/Player.data") で、パスから読む。型に項目を足す、消す、名前を変えるときも、ほかの項目の値は残る (名前で対応づける)。ゲームの DLL が無い、型を消した、というときも、値は JSON のまま保たれて、失われない。Play 中の書き込みは、Stop で、ファイルの値に戻る。 .data は、起動時に、すべて読み込む。Project の Create メニューの C++ Data (ScriptableObject) で、型のひな形を作れる。
  • シーンを切り替えても、GetSingleton の値が残るようになった。 これまでは、LoadScene で、Singleton の値が、初期値に戻っていた。Stop すると、消える。シーンの間で、値を渡す方法 (データアセット、Singleton、残すエンティティ、セーブ値) を、[シーンの切り替え]の文書に書いた。

非互換な変更

Section titled “非互換な変更”

プロジェクト・シーン・アセットの形式や、スクリプトの API が変わったときは、ここに移行の方法を書く。

  • 旧 DataAsset (.asset) を廃止した。 文字列のパス (GetInt("Stats/Hp")) で値を読む、型の無い方式だった。DataAsset* の欄、GetDataAsset、Create > Data Asset、.asset ファイルの読み込みは、無くなった。移行するには、データの形を、SPAN_DATA の構造体で書いて、.data のアセットを作り直す。アセットの typeId 4 は、欠番になった。
  • ゲームのスクリプトの DLL は、作り直しが必要。 CoreContext に、データアセットの関数が足されたため。0.4.0 でビルドした DLL を、そのまま使うことはできない。エディタで開くと、自動でビルドされる。

[0.4.0] - 2026-11-13

Section titled “[0.4.0] - 2026-11-13”

追加

Section titled “追加”
  • Undo / Redo が、ほぼすべての編集に使えるようになった。 新しく対応したもの:
    • コンポーネントの追加、削除、有効 / 無効の切り替え、値の貼り付け。コンポーネントの並べ替え。
    • Prefab の Unpack、Revert All、Apply All(プレハブのファイルも一緒に戻る)。
    • Hierarchy の鍵、Static、表示のアイコン。Prefab とモデルのドロップ。Material のドロップ。MeshFilter の Instantiate Hierarchy。
    • アセットの Inspector(Texture、Font、Sound、Particle、MeshField、Transition、PostProcessProfile、DataAsset、InputMap)。戻すと、メモリ上のアセットも読み直すので、Inspector とゲームの表示も戻る。
    • Animator、Animation Timeline、Sprite Editor。ドラッグは、離したときに 1 回の Undo になる。Sprite Editor の Revert も戻せる。
    • Environment パネルの、ボタンやドロップのような、1 回で終わる操作。
  • 衝突とトリガーを、システムの関数で受け取れるようになった。 System を継承したクラスに、OnCollisionEnter / OnCollisionStay / OnCollisionExit と、OnTriggerEnter / OnTriggerStay / OnTriggerExit を書くだけでよい。CollisionEvent に、トリガーかどうかの印 (IsTrigger) と、相手を取る関数 (GetOther) を足した。
  • アニメーションのイベントを、システムの関数で受け取れるようになった。 OnAnimationEvent(Entity entity, const AnimationEventPayload& payload) を書くと、Animation Timeline のイベントが届く。登録は要らず、あとから作ったエンティティにも、そのまま届く。システムの Run Mode に従い、PlayOnly のシステムには、Play 中だけ届く。これまでの AnimationSystem::OnEvent の登録も、そのまま使える。
  • Rigidbody の子のコライダーが、親の Body の一部として働くようになった(複合コライダー)。 腕や頭に、別のコライダーを付けられる。子のコライダーは、親の形に足され、親といっしょに動く。子を足す、消す、動かす、拡大縮小する、コライダーの値を変える、のどれかをすると、形が作り直される。速度は、そのまま保たれ、質量は、Rigidbody の値のまま。別の Rigidbody を持つ子と、その下は、その Rigidbody のものになる。無効な子は、使われない。トリガーの子は、親の形には入らず、親に追従する、別のトリガーになる。OnTriggerEnter などには、トリガーの子のエンティティが届く。親の Rigidbody との接触は、配られない。どの子のコライダーに当たったかも分かる。CollisionEvent の ColliderA / ColliderB(と GetOtherCollider)と、PhysicsHit の HitCollider に、その子のエンティティが入る。EntityA / EntityB と HitEntity は、これまでどおり、Body の持ち主(Rigidbody のエンティティ)。
  • 物理クエリが、CharacterController に当たるようになった。 Raycast、RaycastAll、SphereCast、OverlapSphere、OverlapBox、CheckSphere、CheckBox が、キャラクターのカプセルを、判定の対象にする。IgnoreEntity と LayerMask も、効く。自分から撃つときは、IgnoreEntity に自分を入れる。
  • カーブのエディタを、パーティクルと Animation Timeline で、共通にした。 新しいキーは Auto(隣のキーから、傾きを自動で決める)で、ダブルクリックで、曲線の上に、形を変えずに足せる。キーを選ぶと傾きの取っ手が出て、ドラッグで形を整えられる(Ctrl を押しながらで、左右を別々に)。右クリックのメニューに、Auto / Free / Linear / Constant / Flat Tangents を追加した。ドラッグ中は、縦の目盛りが動かない。Timeline の Curves では、値の範囲が、曲線に合わせて自動で決まる(これまでは -1〜2 で固定で、100 のような値は見えなかった)。再生位置の線が、曲線の上にも出る。
  • パーティクルの Color と Velocity の曲線を、編集できるようになった。 これまで、キーの数が出るだけだった。Color は R / G / B、Velocity は X / Y / Z の 3 本の曲線で、同じ画面に重ねて編集する。Random Between Two Curves も使える。古い .particle は、そのまま読める(見た目は、変わらない)。新しい形式で保存すると、古い版では、Color と Velocity が読めない。
  • Physics Material を追加した(.physmat)。 摩擦と反発を、アセットで決められる。Create → Physics Material で作り、コライダーの Material 欄に入れる。Material を入れたコライダーでは、Friction と Restitution の欄は使われない(空のときは、これまでどおり、欄の値を使う)。相手の材質と、結合方法(Default / Average / Minimum / Multiply / Maximum)で、1 つの値にする。方法が違うときは、優先度の高いほう(Maximum が最も高い)を使う。どのコライダーにも Material を付けなければ、挙動は変わらない。同じアセットは、全コライダーで共有する。Play 中にアセットの値を編集すると、すぐに効く。 Material 欄の差し替えは、複合コライダーの部品なら、すぐに反映される。ほかのコライダーは、Play のやり直しが要る。CharacterController と MeshFieldChunkCollider には、Material の欄は無い。複合コライダーの子は、子ごとに、別の Material を持てる。
  • Visual Studio のデバッガーを、エディタにアタッチできるようになった。 Tools > Attach Debugger で、ゲームのスクリプト(.h と .cpp)に、ブレークポイントを置いて、Play 中に止められる。Tools > Detach Debugger で外す。スクリプトを Visual Studio で開くときに、自動でアタッチする設定もある(Preferences の Tools、既定は有効)。エディタを、Visual Studio から起動しているときは、アタッチできない。
  • System Panel で、システム名をダブルクリックすると、そのソースが IDE で開く。右クリックのメニューに、Open Source、Show in Project Browser、Copy Name を追加した。ゲームのスクリプトを先に探し、無ければエンジンのシステムを探す。
  • System Panel を作り直した。
    • 一覧は、実行の段階ごとのグループ。見出しのクリックで折りたたみ。見出しに、段階の色、システム数、処理時間の合計を出す。名前は、名前空間を外した短い名前。OFF のシステムは、薄く表示する。
    • 行を選ぶと、右の詳細ペインに、段階、順序、動作モード、FixedUpdate への参加、ソース、処理時間のグラフ、操作ボタンが出る。仕切りで幅を変えられる。右上の ⓘ で、出し入れ。
    • ドラッグでの並べ替えは、同じ段階の中だけ。
    • ツールバーに、All / Game / Core の切り替えを追加した(これまでの「Core を表示」ボタンの置き換え)。
    • 処理時間の列に、全体に対する割合を、細い帯で表示する。詳細ペインにも、割合を出す。
    • 検索欄に、× ボタン、Esc で消す、Ctrl+F でフォーカスを追加した。Add System の検索欄も、同じ部品になった。
  • Add System を、フォルダごとのカテゴリ表示にした。 Scripts の下のフォルダが、そのままカテゴリになる(System/Core/Movement/X.h なら、Core の中の Movement。先頭の System は外す)。検索、All / Engine / Scripts のタブ、直近に追加した 5 件(Recent)、↑↓ と Enter の操作に対応。追加済みのシステムは、既定では隠す(Show attached で表示)。フォルダの情報は、Compile Scripts のときに作られる。
  • エフェクトの編集を、作り直している。
    • Scene ビューに、エフェクトの再生バーを足した。 選んだエンティティと、その配下の VisualEffect を、まとめて操作できる。Restart、Play / Pause、Stop、1 フレームの前後、時間のスライダー、終わったら自動でやり直す、プレビューの速度(0.1x〜2x)。バーは、八か所に固定するか、自由な位置に置ける(Scene ビューの他のパネルと同じ)。
    • Edit 中は、選んだエフェクトだけが再生される。 選ぶと頭から再生し、外すと止まる。親を選ぶと、配下のエフェクトをまとめて再生する。Play を始めると、PlayOnAwake のものが再生される。
    • .vfx の「Preview in Scene」が、別のシーン(Effect Preview Mode)で開くようになった。 開いているシーンはそのままで、空の世界に、エフェクトだけが置かれる。
    • Prefab Mode と Effect Preview Mode の、世界の設定を保存できる。 空、露出、スタジオのライトを、モードごとに ProjectSettings/PreviewWorld.json へ保存する。モードの中で Environment パネルを編集し、モードを出るときに保存される。ライトは、Hierarchy の「Studio Light」を選んで、Inspector で変える。
    • エフェクトの各モジュールに、有効のチェックを付けた。 Emission、Bursts、Shape、Size / Rotation / Speed / Color / Alpha / Velocity over Lifetime、Physics を、値を残したまま、切れる。古い .vfx は、そのまま読める。
    • Effect Editor パネルを足した(Window → Panels → VFX)。 上に再生の操作、左に層のツリー、右にタイムラインを置く。対象は、選んだエンティティの VisualEffect か、選んだ .vfx で、Pin で固定できる。タイムラインには、ルーラー、層の帯、バーストの印、エフェクトの終わりの線、再生位置が出る。Ctrl+ホイールで拡大縮小、中ボタンのドラッグで移動、Fit ボタンで全体を表示する。
    • タイムラインで、つかんで編集できる。 帯の本体で開始、左右の端で開始と長さ、◆でバーストの時刻、ルーラーの取っ手でエフェクトの長さを変える。1 コマに吸着し、Alt で外れる。帯の右端を終わりの線へ寄せると、「終わりまで」に戻る。ルーラーのドラッグで、再生位置を動かせる。編集は、離したときに保存され、Undo は 1 回にまとまる。
    • タイムラインの右クリックのメニューとショートカット。 帯の行を右クリックすると、層の操作(名前の変更、複製、コピー、貼り付け、削除、子の追加)と、バーストの追加(Add Burst Here)と削除(◆の上で)ができる。ルーラーの上にマウスを置いて、Space で再生と一時停止、Home で頭へ、F で全体の表示。層は、子孫ごとコピーして、別のエフェクトへも貼り付けられる(Ctrl+C、Ctrl+V。層のツリーでも同じ)。
    • 層の帯が、エフェクトの終わりの線をはみ出すと、赤い印が付く。 はみ出した部分は再生されない。ルーラーを右クリックして、「Set End to Last Layer」で、終わりを、最後の層の終わりに合わせられる。
    • バーストが、Cycles(くり返す回数)と Interval(間隔)と Probability(確率)で動くようになった。 これまでは、Cycles と Interval が効かず、バーストを時刻の順に並べないと、後ろのものが発生しなかった。順番は、自由になった。ループする層が折り返すときも、層の終わりの近くのバーストを、取りこぼさない。古い .vfx は、確率 1 として、そのまま読める。
    • エンジンに、約 50 種の組み込みテクスチャを入れた。 ぼんやりした円(Soft Circle)、Glow、星(4、5、6、8 方向)、火花の筋、レンズフレア、わっか、波紋、衝撃波、渦巻き、ハート、しずく、三日月、矢印、シャボン玉、花びら、葉、雪の結晶、雲、雷、斬撃の弧、魔法陣、紙吹雪の紙、タイルするノイズ、勾配、煙と炎と爆発ときらめきと雷の Flipbook 用シート(4×4)など。雷のシートは、16 コマが別々の形で、Random Frame にすると、光るたびに違う雷が落ちる。画像のファイルは無く、プログラムで計算して作る(使うときに 1 回だけ。ミップマップつき)。パーティクルの Texture のピッカーに、画像つきで並ぶ。
    • 粒の見た目の拡張。 粒を、カメラを向かず、自分の 3D の向きで回せる(Alignment の Free。紙吹雪、落ち葉、コイン、破片)。X、Y、Z の回転(初期値と、寿命にそった回転の速さの曲線)を、Rotation の項目に並べた。粒の幅と高さを別々に決められる(初期値と曲線)。粒ごとの乱数を、用途ごとに独立にした(大きい粒が、いつも明るい、という相関がなくなる。既存のエフェクトの見た目が、少し変わる)。
    • Flipbook(コマ送りのシート)が使えるようになった。 Rendering の Texture にシートを選び、Flipbook のカードで、列、行、コマの数を決める。進め方は 3 種類。寿命にそって再生する(Over Lifetime。コマの進み方を曲線で決め、Cycles でくり返せる)、一定の速さで再生する(Fixed FPS)、粒ごとにランダムな 1 コマに固定する(Random Frame)。開始のコマを粒ごとにずらせて、次のコマと混ぜる(Blend Frames)と、滑らかにつながる。「2 x 2」「4 x 4」「8 x 8」のボタンで、分割とコマの数を一度に決められる。炎、煙、爆発に使える。
    • UV のスクロールとくり返しが使えるようになった。 UV のカードで、テクスチャをくり返す回数(Tiling)、始めのずれ(Offset)、1 秒に流れる量(Scroll Speed)を決める。粒ごとに始めのずれを変える(Random Offset。軸ごとに、ずれる幅を決める)こともできる。流れる矢印、エネルギーの帯、光の筋に使える。Flipbook がオンの層では、無視される。
    • 色の強さ(Intensity)を足した。 Rendering の項目で、色の RGB に掛ける。いまは 1 を超えた分が切り捨てられる。HDR に対応したあとで、発光として効く。
    • Mask を足した。 2 枚目のテクスチャで、粒の形をくり抜く(Alpha Multiply)、色に明暗のむらを付ける(Color Multiply)、溶かす(Dissolve)。Dissolve は、縁の幅、色、強さを決められ、進み方は曲線で決める。値に使うチャンネルは、Red、Green、Blue、Alpha、Luminance から選ぶ。Invert で、値を反転できる。Tiling、Offset、Scroll Speed、Random Offset も使える。Rendering の Custom Material の欄は、使われていなかったので、なくした。
    • Scene ビューに、エフェクトのギズモが出るようになった。 VisualEffect を持つエンティティに、炎のアイコンが出て、クリックで選べる。エンティティを選ぶと、層のツリーで選んでいる層の、発生形状(Sphere、Hemisphere、Cone、Box、Circle、Point)が、緑のワイヤーフレームで出る。層の位置、回転、大きさ、親子、動きについてくる。層の動き(Position Over Time)は、橙の軌道線で出る(始まりが輪、終わりが丸)。
    • Simulation Space の Local が効くようになった。 Rendering の Simulation Space を Local にすると、粒が、エミッタの位置、回転、大きさについてくる(追従するオーラなど)。重力は、ワールドの下向きのまま。Alignment が Free (3D) の粒と、Fixed Axis の向きも、エミッタの回転に従う。いままでは、Inspector にあっても、World と同じ動きだった。
    • 発生のレートを、曲線で決められるようになった。 Emission の Rate Mode を Curve にすると、層の時間に沿った曲線が、そのまま「1 秒あたりの個数」になる(吹かして止まる噴射など)。曲線は、フレームの間で積分して数えるので、短い山も、数え落とさない。
    • 動いた距離に応じて発生できるようになった。 Emission の Rate over Distance に、1 ワールド単位あたりの個数を入れる(World 空間のとき)。止まっていれば出ず、速く動いても、間隔が同じ。足あとの光、尾を引く火花に使える。
    • 動くエミッタから出る粒が、なめらかに並ぶようになった。 いままでは、1 フレームの粒が、同じ位置にかたまって、速く動くと、塊の連なりになった。レートと距離で出る粒を、前のフレームの位置から、今の位置へ、位置と回転を補間して並べ、早く出た粒ほど、年齢を進める。
    • 速度の引き継ぎ(Inherit Velocity)を足した。 World 空間の粒が、生まれる瞬間のエミッタの速度を、初速に足す(0 で引き継がない、1 でエミッタと同じ速さ)。エンティティを動かしたときも、層の Position Over Time で動かしたときも効く。走りながら出る土煙、乗り物の排気に使える。
    • Pre Warm が効くようになった。 ループするエフェクトで、層の Pre Warm をオンにすると、再生した瞬間から、ずっと前から出ていたような状態で始まる(焚き火、霧、舞う埃など)。前のループの終わりから、通常の更新をそのまま早送りするので、前のループのバーストと、層の動きも、そのとおりに残る。先行させる時間は、Pre Warm の層の寿命の最大(上限 20 秒)。ループしないエフェクトでは、何も起きない。
    • シークと先行が、他のエフェクトの粒を進めなくなった。 早送りは、そのエフェクトの粒だけを進める。いままでは、シークするたびに、画面にある他のエフェクトの粒も進んで消えていた。動く層のシークで、粒の位置が 1 か所にかたまる不具合も直った。
    • 粒の回転(Start Rotation、Rotation over Lifetime)が、見た目に効いていなかった不具合を修正。 回転は計算されていたが、描画に届いていなかった。
    • 作成メニューに、Effects → Effect を足した。
  • マテリアルに、自分で書いた HLSL を使えるようにした(Custom Shader)。 Project パネルの Create → Custom Shader で、雛形のシェーダーが作れる。マテリアルの Custom Shader に .hlsl を指定すると、そのマテリアルは、標準のシェーダーの代わりに、そのシェーダーで描かれる。書くのは、float4 CustomPixel(PSInput input)(色)と、省略できる void CustomVertex(inout float3 localPos, inout float3 localNormal, float2 uv)(頂点の変形)。SceneTime(経過時間)、カメラ、ライト、影、マテリアルのテクスチャが読める。GetAlbedo(標準と同じ色の扱い)、ComputeSimpleLighting(ライトと影)、ComputeSimpleSpecular(ハイライト)、SampleEnvironmentReflection(空の映り込み)、ノイズ(ValueNoise、Fbm)の関数が使える。プロパティは、コメントの // @float(名前, 既定値, 最小, 最大, "表示名")、@color、@vector で宣言する。HLSL の変数は、エンジンが作る。マテリアルのインスペクターに、スライダーと色が出る。シェーダーのファイルを保存すると、自動で読み直す。 文法のエラーのときは、前の見た目を保つ。頂点の変形(CustomVertex)と、CustomPixel の discard は、深度、SSAO、影にも反映される。 書き出したゲームでも動く。 ビルドのときに、シェーダーをクックして、プロパティの一覧と一緒に、Game.pak に入れる。 Custom Shader を使うマテリアルは、GPU 駆動描画の対象から外れる。
    • 内蔵のサンプル(Engine/Shaders/Samples/): Water(波打つ水面。物が入ったときの波紋を、スクリプトから渡せる)、Smoke(煙、湯気の塊)、WindSway(風で揺れる旗、布、草)、Dissolve(溶けて消える)、SimpleWave(書き方を知る、最小のサンプル)。
  • Timeline を追加した(.timeline)。 時間の軸に、エンティティの有効化、スクリプトへの合図、音、アニメーション、エフェクト、プレハブの生成、画面のトランジションを並べて、順に動かす。ムービーのような演出や、イベントの流れを作れる。
    • 使い方。 Create → Timeline で作り、エンティティの TimelinePlayer の Asset に入れる。Play On Start をオンにするか、スクリプトから Play()、Stop()、Pause()、Resume()、SetTime() を呼ぶ。トラックごとの対象のエンティティ(Bindings)は、TimelinePlayer に持つので、同じ Timeline を、別のエンティティにも使える。終わった後の動き(Once、Loop、Hold)と、再生の速さ(Speed)も選べる。
    • 7 種のトラック。
      • Activation: クリップの区間だけ、対象を有効にする。終わった後に、元に戻す、有効のまま、無効のまま、を選べる。
      • Signal: 決めた時刻に、スクリプトへ合図を送る。System に、OnTimelineSignal(Entity player, const TimelineSignal& signal) を書くと届く。名前、文字、小数、整数を付けられる。Pause Playback をオンにすると、その時刻で Timeline が止まり、スクリプトが Resume() を呼ぶまで待つ(会話や、操作の待ちに使える)。終わりは、OnTimelineFinished で受ける。
      • Audio: 対象の AudioSource で、音を鳴らす。Volume、Loop、Clip In(途中から)が効く。区間の終わりで止まる。
      • Animation: クリップのポーズを、Animator のポーズの上に、重みつきで重ねる。Blend In、Blend Out で、前後のポーズと、滑らかにつながる。Clip In、Loop も効く。
      • Effect: エフェクトを再生する。Attach To Target がオンなら、対象に付けて追従させ、オフなら、シーンの直下の位置に出す。Offset、Rotation、Scale で、位置、向き、大きさを決める。区間の終わりで止まる。
      • Prefab: プレハブを生成する。Attach To Target がオンなら、対象の子として、オフなら、シーンの直下に置く。Offset、Rotation を決められ、Destroy At End で、区間の終わりに消せる。
      • Transition: 画面のトランジションを再生する。
    • Timeline パネル(.timeline のダブルクリック、または、Inspector の Open in Timeline)。左に、トラックの一覧(名前、ミュート、削除、ドラッグでの並べ替え、右クリックのメニュー、対象のエンティティの欄)。右に、時間の定規と、クリップ、合図。クリップは、ドラッグで動き、端で伸び縮みする。ダブルクリックで足し、複製と削除ができる。スナップ、ホイールで縦スクロール、Ctrl + ホイールで拡大と縮小、左右の幅と、トラックの高さの調整に対応する。狭いときは、ツールバーが折り返し、欄は、はみ出さない。編集は、Undo / Redo でき(対象の変更、トラックの削除と入れ替えに伴う対象の移動も含む)、ファイルへ自動で保存される。Audio、Effect、Prefab のトラックで、クリップが重なると、赤い枠で知らせる(同時に動かせるのは 1 つだけ)。Audio のクリップの対象に、AudioSource が無いときも、知らせる。Timeline の再生を始めるとき、使うアセットを先に読み込むので、最初に鳴らす、出す、瞬間に引っかからない。
    • Timeline を使うシーンの、対象の欄には、ほかのアセットの欄と同じピッカーが開く(下の Entity のピッカー)。
  • Entity の欄をクリックすると、ピッカーが開くようになった。 ほかのアセットのピッカーと同じ見た目で、検索、リストとグリッドの切り替えができる。上のタブで、Scene(シーンのエンティティ。階層で並ぶ)と、Prefab(Prefab のアセット)を切り替える。Prefab のタブは、Prefab を受け取る欄だけで使える。
  • 動画を再生できるようになった(VideoPlayer)。 .mp4(H.264 の映像と、AAC の音声)などの動画を、ゲームの中で流せる。Windows の Media Foundation を使うので、追加の部品は要らない。
    • 使い方。 Hierarchy の Create → UI → Video Player で、Image と VideoPlayer を持つエンティティができる。動画のファイルは、Project パネルへ入れると、Video アセットになる。VideoPlayer の Video 欄に入れて、Play する。Play On Awake(ゲームの開始で自動再生)、Loop、Volume、Mute、Bus(音声を出すバス)を選べる。スクリプトからは、Play()、Pause()、Resume()、Stop()、Seek(秒)、IsPlaying()、GetTime()、GetDuration()。終わったときは、System の OnVideoFinished(Entity, VideoAsset*) で受ける(Loop と Stop では呼ばれない)。
    • Image の中に流せる。 映像は、同じエンティティの Image のテクスチャとして映るので、Mask(図形)や RectMask2D(四角)の下に置けば、枠の中だけに流れる(ハートの形で流す、など)。Image の PreserveAspect で、縦横比も保てる。画面いっぱいに流すときは、Canvas の下に、画面いっぱいの Image を置く。止めると、Image は元のテクスチャへ戻る。終わると、最後のフレームが残る。
    • 映像と音声は、音声を時計にして同期する。 デコードは専用のスレッドで行う。ゲームを一時停止すると(時間が 0 のとき)、動画も止まる。
    • Inspector に、動画の情報(大きさ、長さ、フレームレート、音声)と、その場で再生できるプレビューが出る(再生、一時停止、停止、シーク、Loop、音量)。書き出したゲーム(Game.pak)でも、再生できる。
    • 再生できるのは、Windows のコーデックで読める動画。H.264 の .mp4 が確実。WebM、VP9、AV1 は使えない。Windows の N エディションは、メディア機能のパックが要る。
  • UI の Mask(図形のマスク)が使えるようになった。 Mask を付けたエンティティの子孫は、そのエンティティの Image の形(テクスチャのアルファ)に切り抜かれる。ハート、円、星、角丸の枠の中だけに、画像や動画を出せる。Show Mask Graphic を切ると、マスクの Image 自身は描かれず、形だけが使われる。Image のテクスチャが無いときは、Image の範囲の四角で切り抜く。マスクの範囲は、そのエンティティの RectTransform の範囲。入れ子にしたときは、内側の Mask だけがかかる。これまでは、Mask を付けても、何も起きなかった。制限: スクリーンスペースの Canvas だけ(World Space の Canvas では、まだかからない)。回転した Mask には、対応していない。

    • LoadGame(スロット): セーブしたシーンが今のシーンと違えば、そのシーンを読み込んでから、状態とセーブ値を戻す。「コンティニュー」に使える(LoadFromSlot は、今のシーンにだけ戻す)。
    • QuickSave() / QuickLoad()(スロット quicksave)、AutoSave(スロット数)(autosave_1 から順に使い回す)、GetLatestSaveSlot()(いちばん新しいスロット)、HasSaveData()(タイトル画面で、コンティニューを出すかの判断)、DoesSaveSlotExist(スロット)。

変更

Section titled “変更”

  • スクリプトの自動ビルドを、控えめにした。 これまでは、Scripts フォルダの中で、ファイルの作成、名前の変更、移動のたびに、エディタが前面にあると、0.5 秒後にビルドして、ホットリロードが走っていた。いまは、変更を覚えるだけで、すぐにはビルドしない。ビルドが始まるのは、(1) VS など、他のアプリから戻ったとき、(2) Play を押したとき(変更があれば、先にビルドして、成功してから Play が始まる。失敗したときは、Play を始めずに、通知を出す)、(3) 手動のとき(Tools > Compile Scripts、プレイバーのビルド表示のクリック、Inspector の Apply to C++ & Compile)。変更があって、まだビルドしていないときは、プレイバーのビルド表示が Changed になる(クリックで、すぐにビルド)。C++ のソースと、フォルダの変更だけを覚える。エディタの一時ファイルなどは、無視する。DirectoryWatcher は、通知の量が多すぎても、止まらなくなった。

  • シーンの描画を、リニア HDR にした。 3D の描画先を、R16G16B16A16_FLOAT のシーンカラーにして、最後に 1 回だけ、ACES のトーンマップとガンマを掛けて、画面用の LDR に変換する。いままでは、材質、スカイ、地形のシェーダーが、それぞれ ACES とガンマを掛けていた。そのため、1 を超える明るさ(パーティクルの Color Intensity など)は切り捨てられ、ブルームが効かなかった。 いまは、1 を超えた明るさが残り、ブルームが掛かる。サムネイル、マテリアルのプレビュー、モデルビューアは、これまでどおり LDR で描く。

    • ポストプロセスは、これまでどおり、表示用の LDR に掛かる。 背景の UI と、ポストプロセスの影響を受ける Canvas も、これまでどおり、ポストプロセスの影響を受ける。
    • Bloom は、トーンマップの前の HDR で処理する専用のパスにした。 段階的に縮小して拡大するので、Blur Radius を大きくしても、反射した光が複製のように見えない。 Bloom のプロファイルの設定(Threshold、Knee、Intensity、Blur Radius、Tint)は、そのまま使える。Blur Radius は、光の広がりの大きさになった。
    • 背景の UI(Sort Order が -1 の Canvas)は、3D の後ろに出る。 HDR のシーンカラーへ、表示用の値のまま描き、トーンマップを通さない。
    • UI、グリッド、ギズモ、選択の枠は、トーンマップで色が変わらない。 ポストプロセスの影響を受ける UI は、トーンマップのあと、ポストプロセスの前に描く。エディタのグリッドとギズモは、ポストプロセスのあとに描く。
    • 見た目が、少し変わる。 パーティクルの色は、リニアに直して描くため、半透明の重なりがガンマ空間のときと違う。
    • UI を光らせられるようになった。 Canvas の Apply Bloom をオンにすると、その Canvas の UI が、ブルームの光源になる。Bloom Intensity は、光の明るさの倍率で、1 を超えると、白い UI も強く光る。UI は、ブルームの光を、文字そのものにも受けて、光ってぼやけて見える(UI の周りだけでなく、UI の上にも、光が乗る)。Ignore Post Process の Canvas には、効かない。Bloom のプロファイルが有効なときだけ、働く。
    • ブルームを有効にした瞬間と、ウィンドウのリサイズで、画面が一瞬壊れる(紫に明滅する)不具合を直した。 ブルームの中間のバッファを、常駐にした。
    • Bloom のプロファイルの判定を、シェーダーのファイル名から、先頭の // @stage(HDRBloom) の宣言に変えた。PostProcess/Bloom.hlsl は、設定項目の宣言だけを持つ。
    • Soft Particle を足した。 層の Rendering の Soft Distance を 0 より大きくすると、粒が、地面や壁など、シーンの面に近づくほど透明になり、面に刺さる所の、くっきりした線が消える(煙、霧、光の玉)。単位は、ワールドの長さ。0 でオフ。透視投影のカメラだけで効く。Multiply と Subtractive の粒、ガラスなどの半透明の物には、効かない。
    • Color over Lifetime を、グラデーションで決められるようになった。 Mode で、Curves(これまでの、RGB の 3 本のカーブ)、Gradient(色とアルファを持つグラデーション 1 本、最大 8 点)、Random Gradients(2 本のグラデーションの間を、粒ごとにランダムに選ぶ)を選ぶ。炎、煙、魔法、火の粉、虹、フェードアウトの、プリセットがある。グラデーションのアルファは、Alpha over Lifetime のカーブに掛かる。
    • 開始の色を、グラデーションからランダムに選べるようになった。 Start Values の Color Mode を Random from Gradient にすると、粒ごとに、グラデーションの、ランダムな位置の色で始まる。Steps を 2 以上にすると、等間隔の位置の色から 1 つを選ぶ(Rainbow のプリセットと Steps 7 で、虹の 7 色のどれかになる。七色の紙吹雪に使える)。
    • Billboard に、Stretched を足した。 粒が、カメラの方を向いたまま、進む向きに伸びる(火花、雨の筋、斬撃、流れ星)。長さは、サイズの高さ × Length Scale + 速さ × Speed Scale で、速い粒ほど長くなる。
    • Cylindrical と Fixed Axis の、Axis を、Inspector で編集できるようになった(これまでは、上向きのまま、変えられなかった)。
    • 粒の速さで、色とサイズを変えられるようになった。 Color by Speed(速さに沿ったグラデーションを、色とアルファに掛ける)と Size by Speed(速さに沿ったカーブを、サイズに掛ける)を足した。Speed Range で、グラデーションとカーブの両端になる速さ(ワールドの長さ/秒)を決める。速い火花ほど、明るく長く、減速する粒ほど、小さくなって消える、といった表現に使う。
    • 発生形状を足した。 Shape に Edge(線分)、Rectangle(長方形)、Donut(輪)を足した。Arc(Circle、Cone、Donut。扇の形に出せる)と Thickness(Sphere、Hemisphere、Circle、Donut。0 で表面だけ、1 で内部の全体)も足した。Thickness は、これまでの Emit From Shell を置き換える(古いデータの Shell は、Thickness 0 として動く)。Shape のカードは、選んだ形状に関係する項目だけを出すようにした。Scene ビューのギズモも、新しい形状と Arc に対応した。
    • 粒の出る向きを、指定できるようになった。 Shape のカードの Direction で、Shape(形状ごとの既定)、Up、Down、Outward(中心から外へ)、Inward、Radial Out(Y 軸から水平に外へ)、Radial In、Custom(ベクトルで指定)を選ぶ。Spherize(中心から外への向きに寄せる)と Randomize(ランダムな向きに寄せる)で、向きを崩せる。Donut の輪を、外向きだけ、内向きだけ、上向きだけにできる。
    • 初速に、軸ごとのランダムなベクトルを足せるようになった。 Start Values の Velocity Min / Max(エミッタの空間)。向きと Speed で決まる速度に、軸ごとに、最小と最大の間の値を足す(Effekseer の、速度のベクトルの範囲に近い使い方)。
    • 粒に、力を足せるようになった。 Physics の下に、6 枚のカードを足した(どれも、既定でオフ)。Acceleration(一定の加速度。軸ごとに、最小と最大の間をランダムに)、Wind(速度を風の速度へ近づける。Influence で追いつく早さ)、Vortex(軸のまわりに回す、軸から離す、軸に沿って動かす。Radius で影響の範囲)、Attractor(1 点へ引き寄せる。負の強さで遠ざける。Falloff は Constant、Linear、Inverse Square。Kill at Center で、届いた粒を消す)、Noise、Speed Limit(速さの上限)。Acceleration、Wind、Vortex、Attractor、Noise は、Local(エミッタについてくる)か World(ワールドで固定)を選べる。
    • Noise に、Curl と Perlin を足した。 Curl は、渦を巻く、滑らかな乱流(煙、魔法の粒)。Perlin は、場所によって向きと強さがばらける。Octaves(1〜3)、Lacunarity、Persistence で細かさを重ね、Scroll Speed で模様を動かし、Strength Curve で寿命に沿って強さを変えられる。Apply は、Force(流される)か Displacement(揺れるだけ)。
    • カーブエディタに、形のプリセットを足した。 Linear、Ease In、Ease Out、Ease In Out、Hold 1、Hold 0、Flip(上下を反転)。Random Between Two Curves のときは、2 本とも置き換わる。
    • Scene ビューのギズモに、Attractor の位置と範囲(桃)、Vortex の軸と範囲(青)を足した。
    • 粒が、地面や壁にぶつかるようになった。 Physics の下の Collision カード(既定でオフ)。Plane(点と法線で置いた平面。Local / World)と、Scene(画面に描かれている面。Mesh Collider や地形にも当たる)を選べる。Bounce(反発)、Dampen(摩擦)、Lifetime Loss(当たるたびに寿命を縮める)、Radius(面から止まる距離)。Settle をオンにすると、遅くなった粒が止まって残り、Rest Time の秒数のあとに、Fade Out Time をかけて消える。紙吹雪のように、地面に落ちて残る表現ができる。
    • 着地した Free の粒は、面に平らに置かれる。 Align to Plane。回転が止まり、0.2 秒で面の向きに倒れる。
    • Sub Emitter を足した。 粒の出来事を引き金にして、別の層が粒を出す。層の Sub Emitter カードで、Source Layer(引き金になる粒を出す層)と、On Birth(生まれたとき)、On Death(消えるとき)、On Collision(面にぶつかったとき)を選ぶ。雨粒が地面に当たったら水しぶき、花火の玉が消えたら星、のような表現ができる。Probability(出る確率)、Min / Max Count(1 回の引き金で出す数)、Inherit Velocity(親の粒の速度を足す)、Align(子の向きを、当たった面の法線、または親の進む向きに合わせる)。子の層の Simulation Space も使える(Local にすると、子が動くものについていく)。この層は、時間では発生しない。親の粒がエフェクトの終わりのあとに消えても、子は出る。Birth の連鎖は、子、孫、ひ孫まで。Death と Collision は、制限なく連鎖する。1 つの層から、子を 4 つまで付けられる。
    • エフェクトに、光、音、カメラの揺れの層を置けるようになった。 層の一覧の上の、電球、スピーカー、カメラのボタンで足す。Light 層: 層の位置に、ポイントライトを置く(色、強さ、範囲と、寿命に沿ったカーブ、色のグラデーション)。爆発の閃光、焚き火の揺らぎ。Sound 層: 層が始まったとき(くり返しの層は、頭に戻るたび)に、音を 1 回鳴らす(音量、音量のばらつき、ピッチの範囲)。Camera Shake 層: 層が動いている間、カメラを揺らす(位置と向きの大きさ、速さ、届く距離、距離による弱まり、強さのカーブ)。複数の揺れは、足し合わさる。揺れるのは、Game ビューだけ。Scene ビューのシークでは、音も揺れも出ない。
    • 粒を、目標へ寄せられるようになった(Move to Target)。 粒の層の Move to Target カード。粒の、物理で動いた位置を、寿命に沿って、エフェクトの目標(VisualEffect の Target)へ寄せる。寿命の終わりに、目標に着く。Easing(Ease In なら、吸い込まれる)、Start(寄せ始める寿命の割合)、Target Offset(目標へのずれ)、Fallback Offset(目標が無いときの、向かう先)。力や衝突は、そのまま働く。帯(Trail)も、寄せた位置についていく。
    • 粒に、帯(Trail と Ribbon)を付けられるようになった。 粒の層の Trail カード。Per Particle(粒ごとに、後ろへ伸びる帯。火花の筋、弾の尾、魔法の軌跡)と、Ribbon(層の粒を、出た順につないだ 1 本の帯。斬撃、雷、紙のリボン)を選べる。Lifetime と Point Count(記録する点の数)、Smoothness(点の間をスプライン曲線で補間する細かさ)、Width(太さ)と Width over Trail(粒から尾への太さのカーブ)、Color over Trail(粒から尾への色とアルファのグラデーション)、Inherit Particle Color、Size Affects Width。Alignment は、View(カメラを向く)、Fixed Axis(面の法線を軸で指定。上なら地面に平らな帯)、Twist(進む向きのまわりにねじれる。紙のリボンのように、ひらひらする。Twist Speed と Twist per Length)。Texture Mode は Stretch(帯全体に 1 枚)か Tile(長さに沿ってくり返し)。Render Particle をオフにすると、帯だけ描く。Linger がオンなら、粒が消えたあとも、帯が尾から消えていく。帯は、ワールド空間に置かれる。層の動き(Motion)と組み合わせると、動く層を 1 つの粒で追う帯(斬撃の軌跡)になる。
    • ゲームのコードから、エフェクトを再生できるようになった(PlayEffect)。 System の PlayEffect(asset, position, rotation, parent, scale) が、エフェクトを出して、ハンドル(EffectHandle)を返す。終わって粒が消えたら、自動で、プールへ戻る。エンティティを作っては捨てないので、頻繁に出しても重くなりにくい。StopEffect(handle) で止め、IsEffectAlive(handle) で、まだ使われているかを確かめる。プレハブで出すエフェクトは、これまでどおり、エフェクトの End Action で、終わったあとの破棄を決める。
    • エフェクトが終わったときの通知(OnEffectFinished)。 System に OnEffectFinished(handle, asset) を足した。発生が止まって、粒が全部消えたときに、有効なすべてのシステムへ配られる。
    • 再生中のエフェクトを、ゲームから変えられるようになった。 SetEffectColor(粒の色に掛ける。アルファも)、SetEffectIntensity(色の強さ。光の層の強さにも)、SetEffectRate(発生数)、SetEffectScale(大きさ)、SetEffectSpeed(再生の速さ)。毎フレーム呼んでもよく、すでに出ている粒の色にも効く。PlayEffect の直後に呼んでもよい。
    • エフェクトに、名前つきの公開パラメータを付けられるようになった。 Effect Editor の Parameters カードで、パラメータ(最大 8 個)を足し、名前、初期値、下限、上限を決める。層の Parameter Bindings カードで、層の項目につなぐ。Particles 層は、Rate(発生数)、Size(粒の大きさ)、Lifetime(寿命)、Speed(初速)、Intensity(色の強さ)、Alpha。Light 層は Range と Intensity、Sound 層は Volume、Camera Shake 層は Amplitude。ゲームのコードから、SetEffectParam(handle, "名前", 値) で変える。つないだ項目に、値が掛かる。Size、Lifetime、Speed は、これから出る粒に効く。それ以外は、すでに出ている粒にも効く。
    • エフェクトを、エンティティに取り付けて再生できるようになった。 PlayEffectAttached(asset, target, offset, rotationOffset, scale, followRotation, lostAction)。エンティティが動くと、エフェクトも付いていく。階層の親子にはしないので、付いていく先が破棄されても、エフェクトは巻き込まれない。付いていく先が無くなったときは、lostAction で、止める(Stop、既定)か、最後の位置に残す(Detach)かを選ぶ。出したあとで取り付ける AttachEffect、取り外す DetachEffect、骨のように深い所のエンティティを名前で探す FindDescendantWithName も足した。
    • エフェクトの品質設定(Low、Medium、High)を使えるようになった。 SetEffectQuality(level) で変える(ゲームの設定画面から呼ぶ)。Low は、発生数 30% で、Trail、Sort、Lit、Distortion を使わない。Medium は、発生数 60% で、Sort と Distortion を使わない。High は、すべて使う。すでに出ている粒は、そのまま消え、以降の発生から変わる。エディタでは、Scene ビューのエフェクトバーの歯車メニューの Effect quality で、試せる。
    • カメラから遠いエフェクトを、間引けるようになった(距離 LOD)。 Play 中だけ。SetEffectLod(enabled, startDistance, cullDistance, minRate)。既定は、40m から発生数が減り始め、120m を超えると止まる(出ている粒は消える)。エフェクトごとに、Effect Editor の LOD Distance Scale で、距離に掛ける倍率を決める。大きな爆発は、大きくして、遠くまで出す。
    • 層の開始を、時刻だけでなく、合図にできるようになった。 層の Start Mode: Time(これまでどおり)、After Layer(Wait For で選んだ層が終わったときに始まる)、On Event(ゲームが、名前つきのイベントを送ったときに始まる)。合図からの遅れは Delay。層の長さ(Duration)が 0 でない層は、その長さで終わる。くり返す層は、終わらない。ゲームのコードから、SendEffectEvent(handle, "名前")(シーンに置いたエフェクトは、VisualEffect の SendEvent("名前"))。エディタのプレビューでは、On Event の層は、頭から始まる。
    • エフェクトの統計を見られるようになった。 Profiler パネルの Rendering Stats に、Particles (alive)(生きている粒の数と、プールの大きさ)、Particle Emitters(使われているエミッタのスロット)、Effects (playing)、Effects (pool: used / free)。Game ビューの Stats にも、Particles と Effects。粒の数は GPU の値で、数フレーム前のもの。
    • 帯(Trail と Ribbon)に、専用のテクスチャを使えるようになった。 Trail カードの Trail Texture。空なら、今までどおり、層の Texture を使う。
    • Mesh の粒の大きさを、X、Y、Z で別に決められるようになった。 Render Mode が Mesh のとき、Size X / Y / Z(それぞれ最小と最大)。Size over Lifetime は、X と Z が同じカーブ、Y が別のカーブ。Mesh に切り替えたときは、見た目が変わらないよう、Y と Z が X のコピーになる。
    • Sound 層の StartTime が 0 のとき、2 回目以降の再生で、音が鳴らない不具合を直した。 再生し直したとき、Sound 層の「鳴らした」印が消えていなかった。
    • 半透明の粒を、奥から手前の順に描けるようになった(Sort Particles)。 粒の層の Rendering カードで、Blend Mode が Alpha のとき、Sort Particles をオンにする。粒が重なっても、手前の粒が奥の粒を隠さない。視点ごとに、GPU で並べ替える。並べる粒は、1 つのビューで 65536 個まで(超えた粒は、並べずに後ろへ描く)。オフなら、費用はかからない。
    • 粒が、シーンのライトを受けられるようになった(Lit)。 Rendering カードの Lit(0 でライトを受けない、1 で全部)。ライトと空の光(環境光)が、粒の色に掛かる。煙や、紙のような粒に使う。影は受けない。
    • 粒を、メッシュで描けるようになった(Render Mode: Mesh)。 Rendering カードの Render Mode を Mesh にして、Mesh にモデルを入れる。複数のメッシュを持つモデルは Mesh Index で選ぶ。粒ごとに、位置、回転(Rotation X、Y、Z と、その速さ)、大きさ(幅が X と Z、高さが Y)、色が付く。不透明で、深度を書き、ライトを受ける。両面。薄い粒は、網目で抜く。紙吹雪、破片、石、葉に使う。同時に使えるメッシュは 8 種類、1 つのメッシュに付き 16384 個まで。
    • メッシュの表面から、粒を出せるようになった(Shape: Mesh)。 Shape に Mesh を足した。モデルの表面から、面積に応じて均等に、粒が出る。向きは、既定で、表面の法線。Scale で、メッシュの大きさを変える。
    • 背景を歪ませる粒(Distortion)を使えるようになった。 Blend Mode に Distortion を足した。粒は色を描かず、背景を、ずらして映す。Distortion Strength(ずれの大きさ。画面の幅の割合)と Radial(オンで、粒の中心から外へずらす。衝撃波。オフで、テクスチャの赤と緑を、向きとして読む。陽炎)。ノーマルマップのようなテクスチャを使う。Distortion は、不透明な物だけを歪ませる。帯(Trail と Ribbon)では、Alpha として描く。
    • 粒が、親の粒についていけるようになった(Follow Source Particle)。 Sub Emitter の On Birth で、Follow Source Particle をオンにする。出た粒は、親の粒を原点にして動き、親が動くと、一緒についていく。弾を粒で作り(Start Speed で飛ぶ、衝突で跳ねる、なんでも)、その周りを回る粒を、親の粒ごとに付けられる。子の粒には、Vortex(原点まわり)や風などの力が、親を基準に働く。Follow Rotation を Velocity にすると、座標の上(Y)が親の進む向きになり、親の進路のまわりを回る。親の粒が消えると、子も消える。この仕組みのため、Update を、親が先に進む段に分けて動かす。
    • VisualEffect のインスペクターに、Target を足した。 Target Entity、Use Target Position、Target Position。
    • 層を動かせるようになった。 層の設定の Motion。Position Over Time のカーブに加えて、Velocity(速度と加速度で動く)、Move To Target(エフェクトの目標へ、イージングをつけて動く。層の長さをかけて移動する)、Orbit(層の位置を中心に、軸のまわりを回る。半径、速さ、始めの角度、半径の倍率のカーブ)を選べる。子の層は、動く親の層についていく。弾が敵へ飛び、その周りを玉が回る、という動きを、カーブを描かずに作れる。Scene ビューの軌道の線も、Motion に対応した。
    • エフェクトに、目標を指定できるようになった。 VisualEffect の Target Entity(動くエンティティなら、追いかける)と Use Target Position / Target Position。スクリプトからは、SetTarget(位置)、SetTargetEntity(エンティティ)、ClearTarget()。Move To Target の層は、目標が無いときは、Fallback Offset だけ動く(エディタでの確認用)。Target Offset で、目標に、ずれを足せる(足元ではなく、胸を狙う、など)。
    • Ground Snap。 平面の高さを手で置かず、エミッタの下の地面に合わせる。地面に Collider が必要。
    • Scene ビューのギズモに、衝突の平面(格子と法線)を足した。
    • カメラの近くで、粒を薄くできるようになった。 Rendering の Near Fade Start / End。カメラからの奥行きが Start より近い粒から薄くなり、End より近いと透明になる。粒が画面を覆うのを防ぐ。
    • 粒の画面上の大きさに、範囲を設けられるようになった。 Rendering の Min Screen Size / Max Screen Size(画面の高さに対する割合)。遠くの粒が小さくなりすぎて消えるのを防ぎ、近くの粒が大きくなりすぎるのを抑える。
    • Particle の Intensity と、Mask の Edge Intensity の説明文を、HDR 対応に合わせた(1 を超えた値が、ブルームで光る)。

  • Play 中の変更は、未保存の印を付けない。 Stop したときは、Play の前の状態に戻る。終了の確認にも、数えない。Play Mode Changes で反映した変更は、これまでどおり、未保存になる。

  • ゲームのスクリプトの DLL は、エディタでは、最適化なしでビルドするようにした。デバッガーで、行どおりに止まるため。あわせて、PDB を作るようにした。ゲームを書き出すときは、別のフォルダ(build/Export)で、最適化ありに作り直す。 初回の書き出しは、数分かかる。書き出しの前に、エディタで、一度、Tools > Compile Scripts を実行しておく必要がある。

  • Prefab の配置、モデルの配置、UI の作成で、新しいエンティティが、親と同じシーンに入るようになった(親がいなければ、アクティブシーン)。

  • システムの実行の段階に、VFX(Camera の後、Audio の前)を足した。ParticleSystem と EffectLifecycleSystem は、ここで動く。

  • システムの実行の順序を、安定させた。同じ段階の中は、SetExecutionOrder(int) の小さい順、同じ値なら、システムの並び順で動く。これまでは、同じ段階の中の順序が、不定だった。

  • System::SetRunsInFixedUpdate(bool) を足した。FixedUpdate に参加するかを、システムごとに決められる。既定は、Camera、VFX、Audio、Render が不参加で、それ以外は参加。

  • Prefab Mode と Effect Preview Mode の見せ方を、作り直した。 Scene ビューの上に出ていたバナーをやめた。上部のパンくずが「‹ プロジェクト › シーン名 › 名前」になり、「‹」で抜ける(Prefab は、未保存の変更があれば、Save / Don’t Save / Cancel を聞く)。Scene ビューには、モードの色(Prefab は青、Effect はオレンジ)の色味と枠が付く。モードの出入りで、元に戻す履歴を消す。モードの中では、Play できない。 Effect Preview Mode の中では、シーンの保存の操作を無効にした。

  • Play 中に、エディタの外周へ出ていた光の枠を、なくした。 目立ちすぎるため。あわせて、設定の Reduce motion も、なくした(光の脈動を止めるだけの設定だった)。バーの色づけと、Game 以外のタブを暗くする処理は、これまでどおり。

  • 影の数値を、1 か所にまとめた。 影のマップの大きさ、法線方向のずらし、PCF の半径を、ShadowSettings.h に置き、シェーダーへは、ライトの定数バッファで渡す。シェーダーの 3 か所にあった、同じ影の関数は、Lighting/ShadowFunctions.hlsli に 1 つにした。見た目は変わらない。

  • ライティングが、Forward+ のタイルカリングを使うようになった。 これまでは、カリングの結果を捨てて、全ピクセルが全ライトを回していた。16x16 のタイルごとに、届くライトだけを回す。ライトが多いシーンで軽くなる。半透明のオブジェクトは、これまでどおり、全ライトを回す。環境変数 SPAN_LIGHT_CULLING で、0(使わない)、1(使う、既定)、2(タイルのライト数を、青から赤の色で見る)を選べる。

修正

Section titled “修正”
  • アセットのピッカーの検索が、大文字と小文字を区別していた不具合を修正。 water でも WATER でも、Water.hlsl が見つかる。
  • Play バーの「>>」(隠れた項目のボタン)を押すと、ImGui のエラーが出る不具合を修正。 左右のボタンの ID が、重なっていたため。
  • マテリアルのプロパティが多すぎると、定数バッファの外へ書き込んでいた不具合を修正。 定数バッファは 1024 バイト。超えたときは、バッファの外へは書かずに、ログにエラーを出す。
  • 書き出したゲームが、起動できなかった不具合を修正。 1 つのシェーダーファイルに、CSPrefilter、PSGlow のような、VSMain、PSMain、CSMain 以外のエントリーポイントがあると、ビルドのときにクックされず、ゲームが「Render Initialization Failed」で止まっていた(HDR ブルームで発生)。名前が VS、PS、CS で始まる関数も、クックするようにした。
  • ブルームで、明るい面が画面に広がると、暗い所まで急に明るくなる不具合を修正。 一番小さい段が、画面全体の平均になっていて、その平均が、画面の全体に足されていたため。小さい段を、画面の全体に広がらない大きさで止める。あわせて、最初の縮小に、明るさの逆数の重み(Karis average)を足した。1 ピクセルだけの強いハイライトが、カメラの動きでちらつく問題も、抑える。
  • DepthNormal の法線が、ビュー空間になっていなかった不具合を修正。 ライト空間の行列で変換していたため、GPU 駆動でない不透明のオブジェクトで、SSAO と、粒のシーン衝突に使う法線が、ずれていた。
  • Animation Timeline の Curves 表示で、Del キーでキーを消せなかった不具合を修正。 削除の処理が、DopeSheet の描画の中にしか無かったため。
  • コライダーの Center が、物理の形に反映されていなかった不具合を修正。 Scene ビューのギズモは、Center の位置に描かれていたが、実際の当たり判定は、エンティティの原点にあった。Center を 0 以外にしていたシーンは、当たり判定の位置が、ギズモの位置に移る。
  • Visual Studio をエディタにアタッチしていると、2 回目以降の Script Build が、LNK1201 で失敗する不具合を修正。 デバッガーが、読み込み中の DLL の PDB を握るためだった。リンクのたびに、PDB の名前を変えて、古い PDB は、読み込み直しのときに消す。
  • ボーンやアニメーションを持つモデルが、インポートの既定の設定で、ボーンとアニメーションを失っていた不具合を修正。 Combine Meshes(既定でオン)は、頂点を事前に変換するため、ボーンとアニメーションを消していた。ボーンかアニメーションを持つモデルは、結合せずに読み込む。静的なモデルは、これまでどおり結合される。古いキャッシュは、自動で作り直される。
  • UI を作るとき、ほかのシーンの Canvas を親にして、親と子が別のシーンになることがあった不具合を修正。同じシーンの Canvas だけを使い、無ければ、そのシーンに新しい Canvas を作る。
  • シーンの読み込みのときに、ゲームの DLL の読み込み前だと、システムが見つからないという警告が出ていた。あとで復元されるので、DLL の読み込み前は、情報に変えた。
  • Play を止めると、加算シーンのオブジェクトが、主シーンに移ってしまう不具合を直した。
  • 加算シーンがアクティブなとき、UI(Canvas、Button など)を作ると、主シーンに保存される不具合を直した。子のエンティティも、同じシーンに入る。
  • エンティティの削除を Undo すると、元のシーンではなく、アクティブシーンに戻る不具合を直した。
  • コンポーネントの削除を、Undo で戻せなかった不具合を直した。プロパティを持たないコンポーネントも、戻せる。
  • スクリプトをコンパイルすると、Add System の候補から、エンジンのシステムが消える不具合を直した。
